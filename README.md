# houkago-okujou（放課後の屋上）

放課後の屋上で踊る16秒のループ動画を作るコードです。
振付はコンテでカットごとに決めて AI で生成し、曲も歌入りで生成。曲を文字起こしして歌詞が歌われる秒を測り、カット割り・画面の歌詞・決めの振りをその秒に合わせています。
合成・文字・演出は Python（NumPy・OpenCV・Pillow）と ffmpeg で1コマずつ計算しています。After Effects などの編集ソフトは使っていません。

## できるもの
- `out/okujou.mp4`：1920×1080・30fps・16.0秒（120 BPM × 32拍）。最後の寄りから頭の商品カットへ戻るのでループ再生できます
- `out/process.mp4`：作り方の動画（20秒）

| 秒 | 歌 | 画面 | ダンス |
|---|---|---|---|
| 0.0–1.0 | 六時間目の | ローアングルの商品カット（手前に缶2本、画面内の太陽） | 腕の X から開く |
| 1.0–7.0 | チャイムで／階段を／駆け上がる | 正面。左に歌詞が1行ずつ積まれる（キャラの後ろ） | 指でチャイム → 横ステップ → もも上げ |
| 7.0–11.0 | 空に一番／近いステージ | 斜め。名札・四角のグリッド・右下に歌詞 | 空を指さす → 床 → 腰に手 |
| 11.0–12.0 | （伸ばし） | 階段室。画面より大きい「ROOFTOP」が流れる | 跳んで着地 |
| 12.0–14.0 | Dance Dance Forever | 白フラッシュ。「Dance」と歌う所で DANCE が塗りに | 頭上で X → 手をたたく → V |
| 14.0–15.0 | — | CREW。拍ごとにカメラが揺れてブレ・グリッチ | こぶしを交互に突く |
| 15.0–16.0 | Rooftop Dance Crew | 俯瞰の寄り。紋章と縦書き | X のまま、目を開けて笑顔 |

## 分担
| 工程 | 使ったもの |
|---|---|
| キャラの設定画 | ChatGPT |
| 最初のコマの素材（キャラのダンス動画） | Higgsfield（[motion-reel](https://github.com/aiimpl/motion-reel) と同じ素材） |
| カットごとのダンス（7カット・25本から選択） | Wan2.2 I2V 14B＋lightx2v 4step、RunPod の A100（[gen/README.md](gen/README.md)、振付は [conte/CONTE.md](conte/CONTE.md)） |
| 曲（歌入り） | ACE-Step 1.5 turbo、RunPod の A100 |
| 歌詞の秒の計測 | faster-whisper（medium） |
| 背景6枚・商品の缶 | GPT Image 2.5（プロンプトは [docs/prompts.md](docs/prompts.md)） |
| コンテ・合成・演出・このリポジトリのコード | Claude Opus 5.5 |

GPU 代は Pod 3回で約3ドル（A100 SXM $1.59/時）。

## 動かし方
必要なもの：Python 3.10 以上、ffmpeg

```sh
pip install -r requirements.txt
# assets/ に素材を置いてから（assets/README.md）
make
```

M5 の Mac（CPU のみ）で、本編が約6分、作り方の動画が約5分です。

```sh
python src/render.py --sheet          # 0.5秒ごとのコマを並べた一覧 out/sheet.png（30秒ほど）
python src/render.py --still 6.0 11.6 # その秒の1コマだけ PNG に
python src/render.py --preview        # 960×540 で書き出す
```

素材（ダンス動画・缶・背景）と生成したダンスのクリップはリポジトリに入っていません。置き方は [assets/README.md](assets/README.md)、ダンスの作り方は [gen/README.md](gen/README.md) を見てください。

## しくみ
| ファイル | 内容 |
|---|---|
| `conte/CONTE.md` | コンテ。振付の方針、カットごとのダンス（決めの形と歌詞の秒）、選んだシードと理由 |
| `gen/` | ダンスの生成。コンテの振付をカットごとの Wan2.2 I2V ワークフローにして、使い捨ての Pod で回す |
| `src/key.py` `src/key_cuts.py` | キーイング。緑が赤・青よりどれだけ強いかで透明度を決め、縁の緑を抑える。素材の左右の端は腕が画面の外へ出るのでなめらかに消し、上下は髪と足を削らないよう短くする。コマごとに足の先の高さも記録する |
| `src/comp.py` | 合成。背景の絵をカメラ（中心・倍率・回転）で切り取り、キャラの足の先を絵の床の高さに合わせて同じカメラで写す。床の影（シルエットを床の線で折り返して太陽の反対へ倒す）と足元の濃い影、右上からの日差しのふち、背景の明るさを輪郭ににじませる処理、画面内の太陽・ブルーム・色収差・ブレ・グリッチ |
| `src/scenes.py` | カット割り。ダンスはカットごとに「動画の秒 → クリップの秒」を区間ごとに線形で対応させ、決めのコマ（頭上の X、手をたたく、V など）が文字の出る拍に来るよう再生速度を変える。カメラは「キャラの身長が画面の何割か・足が画面のどこか」で指定する（背景ごとに床と地平線の高さを測っておき、目の高さのカメラなら地平線が身長の81%に来ることから立つ人の大きさを出す）。文字は背景とキャラの間に描くので、キャラの後ろを通る |
| `src/typo.py` | 文字（Pillow で描いてキャッシュ）、縦書き |
| `src/prep.py` | 缶の切り抜きと紋章（キャラの X 字ヘアピンがモチーフ） |
| `src/pick_song.py` | BGM の切り出し。ACE-Step 1.5 で作った曲（gen/build_stage.py）から、120 BPM の拍の頭にそろえて16秒を取る |
| `src/lyrics_time.py` | 曲を文字起こしして、歌詞が歌われる秒を測る（faster-whisper）。カット割り・画面の歌詞・振りの決めはこの秒に合わせた |
| `src/process.py` | 作り方の動画（20秒）。コンテ・生成したクリップ・曲の波形と歌詞の秒・合わせる前後・層を1つずつ足す絵を、本番の素材とコードから出す |
| `src/render.py` | 1コマずつ ffmpeg にパイプで渡して mp4（yuv420p）に。最後に曲を合わせる |
