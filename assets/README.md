# 素材を置く場所

どれもリポジトリには入っていません（生成した素材のため）。同じ名前で置いてください。

| ファイル | 中身 | 今回使ったもの |
|---|---|---|
| `dance_green.mp4` | グリーンバックで踊る全身の縦長動画（約15秒） | Higgsfield で作った 720×1280・24fps・361コマ（motion-reel と同じ素材） |
| `can_green.png` | グリーンバックの商品画像 | PINPOP（架空の缶ジュース）1024×1024 |
| `bg_low.png` | 背景：ローアングル・画面内に太陽（商品カット） | GPT Image 2.5 で作った 2688×1520 |
| `bg_front.png` | 背景：屋上を正面から（歌詞1） | 同上 |
| `bg_diag.png` | 背景：フェンスが斜めに奥へ（歌詞2） | 同上 |
| `bg_build.png` | 背景：階段室と給水塔（ROOFTOP） | 同上 |
| `bg_front2.png` | 背景：屋上を正面から・別案（DANCE / CREW） | 同上 |
| `bg_top.png` | 背景：俯瞰で床（最後の寄り） | 同上 |

背景は、`bg_front.png` を作ってから、それを参考画像にして「同じ屋上を別のカメラで」と頼んで残りを作りました（プロンプトは [../docs/prompts.md](../docs/prompts.md)）。
別の背景に替えるときは、`src/scenes.py` の `PLATE_DEFS` に床と地平線の高さ（絵のピクセル）を書き直してください。
