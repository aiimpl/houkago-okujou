# コンテ：放課後の屋上

16秒・120 BPM × 32拍（1拍＝0.5秒）。ダンスはカットごとに生成する。最終的なカット割りは末尾の「作り直し（3回目）」の表。

## 振付の方針
| 方針 | やり方 |
|---|---|
| 1カットに1つ、小さい画面でも読める決めの形 | カットごとに「決め」を1つ決める（下の表の太字） |
| 上半身だけで踊らない | 足を肩幅より広く踏んで、膝で拍を取り、体重を左右に移す |
| 大きな動きを、文字の出る拍に合わせる | 生成後に、区間ごとに再生速度を変えて決めのコマを拍へ |
| 動く → 止めて見せる | 決めの後に1〜2拍止める |
| 仕草はカメラに向けて胸より上で、表情も変える | 笑顔 → 口を開けた笑い → ウインク |
| ループの継ぎ目 | 最初と最後を同じ「X」の形に |

振りの軸はキャラの **X 字ヘアピン**。両腕を交差させた「X」をモチーフにして、最初・DANCE・最後に出す。
歌詞に合わせた仕草（チャイム、駆け上がる、空）も入れて、歌詞を踊る。

## 最初のダンス素材（1本の15秒）の問題
- 同じ小さな弾み・こぶしを振る動きの繰り返しで、決めの形が無い
- 腕を横に振ると素材の画面の端から出る（切り抜きの縁で消える）。跳ぶと頭が上の端に当たる
- 拍・歌詞・文字と動きが結びついていない（素材の時間をそのまま流しているだけ）
- 24fps・720×1280

## カットごとのダンス
「拍」は曲の頭からの拍番号（0〜31）。**太字＝決め**（文字・カメラの山と同じ拍）。

| # | 秒 | 拍 | 画面（今の版と同じ） | ダンス |
|---|---|---|---|---|
| C1 | 0.0–1.0 | 0–1 | ローアングルの商品カット、手前に缶 | 両腕を胸の前で **X に交差**してうつむいた形から始まり、拍1で顔を上げて笑い、腕を左右にぱっと開く |
| C2 | 1.0–4.5 | 2–8 | 正面・左に歌詞「六時間目の／チャイムで／階段を／かけ上がる」 | 右へステップ・左足をタッチ、を膝のバウンスで繰り返す（肩も弾む）。拍3「チャイムで」で **人差し指を立てて空中を2回つつく（チャイムが鳴る仕草）**。拍6「階段を」で左右を見る。拍7〜8「かけ上がる」で **膝を高く上げてその場で駆け足**、腕も大きく振る |
| C3 | 4.5–8.0 | 9–15 | 斜め・名札・右下に歌詞「空にいちばん／近いステージ」 | 拍9〜12でカメラへ2歩、肩を揺らして歩いてくる（体重移動を大きく）。拍13「近いステージ」の直前で **右腕をまっすぐ空へ伸ばして指さす**、拍14で腕を振り下ろして足元の床を手のひらで示し（ここがステージ）、拍15は片手を腰に置いて首をかしげて止める |

| C5 | 10.0–12.0 | 20–23 | 正面・DANCE（拍21・23で塗り） | 拍20：両手を胸の前で構える。**拍21：両腕を頭上へ突き上げ、手首を交差して X**（塗りの瞬間）。拍22：腕を下ろして胸の前で手を1回たたく。**拍23：両腕を大きく V に開いて小さく跳ぶ** |
| C6 | 12.0–14.0 | 24–27 | 正面・CREW・カメラが揺れる（拍ごとに揺れ） | 1拍ごとに、左右の斜め上へこぶしを交互に突き出す（右上・左上・右上・左上）＋同じ側の足で前へキック。突きの瞬間がカメラの揺れと同じ拍 |
| C7 | 14.0–14.5 | 28 | 寄り・RTDC | 両手の人差し指と親指を立て、カメラへ向けて突き出す（両手の指鉄砲） |
| C8 | 14.5–16.0 | 29–31 | 俯瞰の寄り・紋章・縦書き | 腕を引いて **胸の前で X に交差**、**ウインク → 目を閉じて笑う → 目を開けてカメラを見て笑顔で終わる** → C1 の X の形へループ。全身のクリップでは顔が小さく目が崩れたので、腰から上の寄りで作り直した（c8） |

## 生成の決まり
- 1カット＝1本の生成（必要な長さ＋前後に少し）。最初のコマは、今のキャラをグリーンバックに置いた静止画
- 腕を広げても切れないよう、キャラの周りに余白を取った画面で作る（今の素材より引きの全身）
- 回転は入れない（崩れやすい）。回って見せたい所はコードで画面ごと振る
- 手・指・顔は崩れやすいので、プロンプトで「指は5本」「顔ははっきり」と名指しする
- 各カット2〜3シードを作って、目で選ぶ（選んだ理由をこのファイルに残す）
- 生成後、決めのコマを探して、区間ごとの再生速度で決めを拍に合わせる。fps は 30 にそろえる

## 作り直し（2026-09-28・2回目）
- **最後の寄り（c8_lean_a）**：全身の c7 は顔が小さく、ウインクで目が崩れ、止めも目を閉じたままだった。
  c7 の目を開けた X のコマ（26）を Qwen-Image-Edit で腰から上の寄りに描き直し（close_a_s2）、そこから Wan で作った。
  4本（揺れる／のり出す × 2枚）のうち、ウインク → 目を閉じて笑う → 目を開けて終わる lean_a を採用。33コマ目だけ目が滲むので飛ばす
- **曲**：motion-reel と同じ合成の曲をやめ、ACE-Step 1.5 で作った（歌入り2・インスト2、各32秒、120 BPM）。
  歌入りは画面の歌詞をそのまま歌わせた。採用は song_vocal_s31 の頭16秒。4案は out/songs/ で聴き比べられる
